# 📦 Blinkit Data Analysis Dashboard (Power BI)

This Power BI project presents a comprehensive and interactive dashboard to analyze Blinkit outlet performance across diverse dimensions such as **location tier, outlet size, and outlet type**. It provides business insights into sales performance, customer ratings, and product availability, enabling data-driven decision-making for operational efficiency.


## 🔧 Data Preparation & Transformation

The dataset underwent structured cleaning and transformation in Power BI to ensure accurate and meaningful analysis:

- Removed nulls and standardized inconsistent entries  
- Converted data types and formatted fields for consistency  
- Created calculated columns for metrics like Total Sales and Average Rating  
- Established data relationships for a unified data model across outlet attributes


## 📊 Data Visualizations in Power BI

The dashboard is designed with user experience in mind, offering easy navigation and high-impact visuals.

### 📈 Charts & Visual Elements

- 🎯 **KPI Cards** – Avg. Sales: ₹140.99 | Avg. Rating: 3.92 | Items: 8.5K+ | Total Sales: ₹1.2M  
- 📉 **Line Chart** – Sales trends by year of outlet establishment  
- 🧱 **Stacked Column Charts** – Sales by Outlet Size and Tier  
- 🥇 **Bar Chart** – Top Outlet Types by Sales  
- 📋 **Tables** – Outlet performance metrics with dynamic ranking  
- 🎛️ **Slicers** – Location Tier, Outlet Type, Outlet Size for detailed drill-downs

## 🔍 Key Insights

- 🏬 **Medium-sized outlets** and **Tier 3 cities** contributed the highest to overall sales  
- 📅 **Seasonal patterns** observed based on outlet establishment year  
- 🛒 **Supermarket Type1** emerged as the top-performing outlet type with ₹7.87M in sales  
- 🔍 Interactive filters allow users to explore regional performance and category breakdowns effortlessly


## 🛠️ Tools Used

- 🧹 **Power BI** – Data cleaning, modeling, and visual storytelling  
- 🧠 **DAX** – To create dynamic KPIs, calculated columns, and interactive measures
